# Search visibility setup — Head Exercise Application

The public site is intentionally focused on four useful pages:

- Home: the live movement counter.
- Quick guide: how to use camera mode, manual mode, session controls and CSV export.
- Privacy: camera processing, external dependencies and session data handling.
- Safety: intended use, limitations and when to stop.

Each page has a unique title, description, canonical URL and structured data. The sitemap lists only these four canonical pages.

## Search Console

1. Add the URL-prefix property https://myg-1107.github.io/Head-Exercise-Application/ in Google Search Console.
2. Complete site ownership verification using the exact value supplied by Search Console.
3. Submit https://myg-1107.github.io/Head-Exercise-Application/sitemap.xml.
4. Use URL Inspection on the homepage, quick guide, privacy and safety pages to check crawling and canonical selection.
5. Monitor impressions, clicks and queries. A sitemap helps discovery but does not guarantee indexing or ranking.

## Content policy

- Keep pages focused on the actual application and its controls.
- Do not publish repetitive articles merely to increase page count.
- Do not add fabricated testimonials, case studies, medical claims or unverified performance numbers.
- Review privacy wording whenever a dependency or data flow changes.

The old article archive has been removed. Previously indexed article URLs will no longer be available and may need to be recrawled by search engines. The sitemap now advertises only the four retained pages.

No metadata or code change guarantees a ranking, indexing date or business outcome. Useful content, accurate implementation, accessibility, site reputation, competition and ongoing measurement all matter.

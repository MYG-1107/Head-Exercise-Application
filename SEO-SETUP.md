# Search visibility setup — Head Exercise Application

The homepage contains the working application and a first-session walkthrough. The help centre contains 20 focused guides covering the application's controls, setup, camera troubleshooting, session data and safety. Each page has a unique title, description, canonical URL, Open Graph/Twitter metadata and appropriate JSON-LD.

## Search Console

1. Add the URL-prefix property https://myg-1107.github.io/Head-Exercise-Application/ in Google Search Console.
2. Complete Google's site ownership verification using the exact value supplied by Search Console.
3. Submit https://myg-1107.github.io/Head-Exercise-Application/sitemap.xml.
4. Use URL Inspection on the homepage, help centre and selected guides to check crawling and canonical selection.
5. Monitor impressions, clicks and queries. A sitemap helps discovery but does not guarantee indexing or ranking.

## Editorial quality

- Each guide answers a specific question about using this application.
- Avoid duplicate or unrelated articles that do not help an application user.
- Keep visible content accurate to current controls and actual behaviour.
- Do not add fabricated testimonials, case studies, medical claims or unverified performance numbers.
- Review privacy wording whenever a dependency or data flow changes.

No metadata or code change guarantees a ranking, indexing date or business outcome. Useful content, accurate implementation, accessibility, site reputation, competition and ongoing measurement all matter. Meta keywords are supplemental; do not stuff them or rely on them for ranking.

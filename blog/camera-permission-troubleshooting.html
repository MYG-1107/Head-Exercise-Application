Camera Permission: How to Allow or Restore Access

Camera mode requires permission from the browser and operating system. This guide explains how to respond to the permission prompt and what to check when access has previously been blocked.

8 November 2026·Application help guide

Start from the application

Choose Start camera to trigger the browser permission request. Read the browser prompt and allow access only if you are comfortable using the camera. The application does not need camera permission to use manual mode.

If you selected Block

Browsers commonly let you change camera access from the site information or privacy controls near the address bar. Open the site's permissions, allow camera access for this website and reload if the browser asks you to. Exact steps and labels vary by browser and operating system.

Check the device itself

Another application may already be using the webcam, or the operating system may block browser access. Close other video applications, check the system camera privacy setting and confirm that the correct camera is connected and available.

Continue without a camera

If you cannot or do not want to grant permission, switch to manual mode. It does not request camera access and lets you enter completed cycles yourself. Manual entries are not verified by camera tracking.

Key points

  • Permission is requested only after choosing camera mode.
  • Review site and operating-system privacy settings if access is blocked.
  • Close other apps that may be using the camera.
  • Manual mode does not require camera permission.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

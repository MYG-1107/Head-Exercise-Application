How to Pause, Resume or Stop a Session

Pause and Stop have different purposes. Pausing temporarily suspends the current session, while Stop ends the active run and releases the camera stream.

8 November 2026·Application help guide

Pause when you need a break

Select Pause to suspend the running session. The timer stops advancing and the camera is released by the application. This helps ensure that a paused session does not keep an active camera stream running in the background.

Resume camera mode carefully

When you resume a paused camera session, the application must request camera access again and re-establish a reliable tracking baseline. Follow the browser permission prompt if it appears and allow calibration to complete before relying on new direction estimates.

Stop to finish the run

Select Stop to end the active session. The camera stream is released, and the interface returns to a non-running state. You can still review the counts held in the current page until you reset, refresh or close the page.

Manual mode and session state

Manual sessions do not need camera access, but the same pause and stop concepts apply to counting. Choose the controls deliberately and use the status message to understand whether the app is ready, running, paused or stopped.

Key points

  • Pause suspends the current session.
  • Resume may require camera permission and recalibration.
  • Stop releases the camera and ends the active run.
  • Counts stay in the current page until reset or reload.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

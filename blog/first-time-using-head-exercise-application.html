Getting started

Your First Session with Head Exercise Application

The application opens directly to its movement counter. There is no account creation or login screen. This guide walks through the first session and explains what to expect before using camera or manual mode.

8 November 2026·Application help guide

Open the application

Open the website in a modern browser. The counter is on the first page, so there is no registration step, dashboard or separate account area. Read the short privacy and safety notes before starting. The application is a counting utility, not a medical assessment or an exercise prescription.

Choose how to count

Camera mode can estimate direction from facial landmarks after you press Start camera and grant browser permission. Manual mode does not ask for camera access; it records the direction you choose after completing a movement cycle. Use the mode that is practical and comfortable for you.

Understand a completed cycle

The counter is designed to count a direction and a return to centre as one repetition. In camera mode, the estimate may vary with camera position, lighting and tracking quality. In manual mode, the entry is self-reported. A number is a record of the interaction, not proof of correct technique.

Finish and review

Pause or stop when you need to. The counts and elapsed time remain in the current page session. Choose Export summary to download a CSV file to your device. Refreshing or closing the page clears the current session values.

Key points

  • No account or login is required.
  • Camera access is optional and starts only after you choose camera mode.
  • Manual mode is available without camera permission.
  • CSV export happens only after you select the export control.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

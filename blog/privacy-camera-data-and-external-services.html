Privacy

Camera Privacy, Session Data and External Services

The application is designed to run as a browser-based counter without an account. This guide explains what the app does locally and which external resources camera mode and typography currently use.

8 November 2026·Application help guide

No account or login

The tracker opens directly without creating an account. It does not provide user profiles or a server-side session history. Counts and elapsed time remain in the current page memory and clear after the page is refreshed or closed.

Camera and tracking assets

Camera permission is requested only when camera mode starts. Video frames are passed to the tracking library in the browser; the app has no feature that intentionally uploads those frames. The library and model assets are currently loaded from jsDelivr, which receives ordinary requests for those resources.

Other external requests

The stylesheet references a public font CDN. Requests to external services can expose standard connection information such as IP address, requested URL and browser details. The app cannot control the independent logs or privacy practices of those services.

CSV and browser cache

A CSV file is created only when you select Export summary, and it is downloaded by your browser rather than uploaded by the application. A service worker may cache same-origin app files for offline use; it does not store camera frames or session counts.

Key points

  • No account or login is needed.
  • Camera access is optional and initiated by the user.
  • Session values remain in page memory until reload or close.
  • The browser downloads CSV exports locally.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

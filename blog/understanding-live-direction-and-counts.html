Understanding Live Direction and Session Counts

The session panel separates the current estimated direction from completed repetitions. Each display has a specific role, so a temporary direction label should not be mistaken for a completed count.

8 November 2026·Application help guide

Current direction is a live status

The direction panel displays the current state estimated by camera mode or the latest state supplied through manual mode. In camera mode, the estimate can change while the tracking model processes frames. It is not a permanent record of completed repetitions.

The repetition total shows completed cycles

The total increases when the counting rules recognise a completed cycle. The individual Up, Down, Left and Right figures show how the total is distributed. A temporary direction without a return to centre should not be treated as a completed cycle.

The timer records the active session

The elapsed-time display tracks the session while it is running. Pausing stops active timing until the session resumes. Reset clears the session values. The timer is a simple elapsed-time indicator and is not a clinical activity monitor.

Progress depends on the selected goal

The target selector changes the reference goal shown by the progress bars. It is a user-selected tracking value, not a recommended exercise volume. Reaching a displayed goal should never be treated as a reason to continue through discomfort.

Key points

  • Live direction is different from a completed repetition.
  • Per-direction values show the distribution of completed cycles.
  • The timer pauses with the session.
  • The goal is a display setting, not an exercise recommendation.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

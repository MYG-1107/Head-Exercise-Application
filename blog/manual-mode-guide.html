Using Manual Mode Without a Camera

Manual mode gives you a way to use the counter without granting camera access. You select a direction after completing a movement and returning to your centre position.

8 November 2026·Application help guide

Switch to manual mode

Use the mode control when a camera session is not running. The camera preview is hidden and the application does not request camera permission for manual entries. The interface presents four direction controls: Up, Down, Left and Right.

Enter a completed cycle

Tap the relevant direction button only after you have completed the movement and returned to centre. The counter records the direction you selected. The application cannot observe or verify the movement in manual mode, so entries should be understood as self-reported.

Review goals and progress

The goal selector controls the target used by the session counter. Direction totals and overall progress update as manual entries are made. The goal is a display and tracking setting; it is not a recommendation about how many movements anyone should perform.

End and export

Pause or stop the session using the session controls. Export summary downloads the current session as a CSV file when you choose it. The application does not upload the exported file. Refreshing or closing the page clears the in-page session.

Key points

  • Manual mode does not use the webcam.
  • Choose one direction per completed movement-and-return cycle.
  • Manual entries are not verified by the application.
  • You can export the session only by selecting Export summary.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

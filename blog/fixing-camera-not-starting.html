Camera Will Not Start: Troubleshooting Guide

A camera session can fail before the preview appears or while the tracking library loads. Work through these checks one at a time rather than repeatedly pressing Start.

8 November 2026·Application help guide

Use a supported secure page

Camera access normally requires a secure browser context. Open the official HTTPS application URL in a current browser. An embedded preview, local file opened directly or restricted in-app browser may not provide the required camera APIs.

Check permission and device availability

Confirm that the browser is allowed to use the camera and that the operating system has not disabled it. Close video meeting apps and check that the intended camera is connected. If multiple cameras exist, use the available camera control when a session is active.

Check the connection

Camera mode loads tracking code and model assets from an external content delivery service. A network filter, offline connection or temporary service issue can prevent those assets from loading. Try again on a trusted connection, or use manual mode while camera assets are unavailable.

Recover safely

If the session reports an error, stop and wait for the camera indicator to turn off. Reload the page only after the stream has been released. If the camera continues to fail, switch to manual mode rather than treating repeated errors as a requirement to continue.

Key points

  • Use the HTTPS site in a current browser.
  • Check camera permissions and device privacy settings.
  • Camera tracking assets require an internet connection.
  • Manual mode is the fallback when camera setup fails.
Use and safety note

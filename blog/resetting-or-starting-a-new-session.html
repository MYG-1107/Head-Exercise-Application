Resetting Counts and Starting a New Session

Reset clears the current in-page session values so you can start again. It is different from pausing or stopping, which control the active session without serving as a complete reset.

8 November 2026·Application help guide

Know when to reset

Use Reset when you intentionally want to clear the direction totals and elapsed time. It is useful before a new practice session or when you have entered test values. Check the visible counts before confirming the action because the current in-page values will be replaced.

Stop active tracking first

The application restricts some settings while a session is running. Stop or pause the active session before changing modes or resetting. When camera mode is active, make sure the camera is no longer running before starting a separate session.

What Reset changes

Reset clears the current direction counts, total, timer and relevant movement state. In camera mode, the neutral reference may need to be established again. The application does not save an earlier session history that can be restored after reset.

Export before clearing if needed

If you need a record of the current session, choose Export summary before refreshing or resetting. The CSV is generated locally in your browser after you request it. The application does not upload the exported file.

Key points

  • Reset is a clearing action, not a pause.
  • Stop active camera tracking before starting another session.
  • Export a CSV first when you need to keep a copy.
  • Refreshing the page also clears in-memory session values.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

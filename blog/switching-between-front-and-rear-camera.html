Switching Between Front and Rear Cameras

Devices may expose more than one camera. The Flip control can request the alternative facing mode, but browser and device support differ.

8 November 2026·Application help guide

When the control is available

The camera flip control is enabled during an active camera session when the application can request camera access. If the control is disabled, first check that camera mode is running and a stream has been acquired.

What happens during a switch

The application requests a stream using the alternative facing preference. The browser or device may select a different camera or keep the existing one if the preference is unavailable. Wait for the preview and tracking state to stabilise after switching.

Re-establish the reference

Changing the camera position changes the view of the face. The previous neutral reference may no longer be suitable, so the tracker may need a new calibration. Hold a comfortable forward-facing position while the calibration indicator advances.

If switching fails

Some devices expose only one camera or restrict switching while another application is using it. Stop and restart camera mode, check browser permissions or continue in manual mode. Do not assume the camera changed unless the preview confirms it.

Key points

  • The Flip control is for active camera mode.
  • Device and browser support determine which camera can be selected.
  • A camera change may require recalibration.
  • Manual mode remains available if camera switching fails.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

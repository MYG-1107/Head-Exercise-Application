Counting and progress

Setting a Session Goal Safely

The application includes a goal selector so the counter can display progress against a value you choose. The setting is for organising the on-screen count; it is not a health or exercise recommendation.

8 November 2026·Application help guide

Choose a display target

The Goal per direction selector offers a small set of values. Changing it updates the target shown beside the individual direction counts and the overall progress display. The control is available when the session is not running, so the session logic has a clear target.

Read the progress indicators

Each direction card shows its completed count against the selected target. The overall progress indicator provides a combined view. These are interface summaries of recorded entries, not measurements of movement quality, effort or safety.

Avoid treating a number as advice

A larger goal is not automatically better. Appropriate movement depends on the individual and their circumstances, which the application does not assess. Do not use a target as a reason to move further, faster or longer than feels comfortable.

Change or reset when needed

Choose a new target between sessions, or reset the current session before beginning another. If the application has reached a goal, you can stop and review the result. There is no requirement to complete every displayed target.

Key points

  • The target is a user-controlled interface setting.
  • Progress counts recorded entries only.
  • Goals are not exercise prescriptions.
  • Stop or pause whenever you need to.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

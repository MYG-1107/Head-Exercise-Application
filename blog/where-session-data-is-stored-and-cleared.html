Where Session Data Is Stored and How It Is Cleared

The application separates temporary session values from cached website files. Understanding that difference helps explain what is cleared when you refresh, reset or clear browser site data.

8 November 2026·Application help guide

Session values stay in page memory

Direction totals, the elapsed timer and other active-session values are held by the page while it is open. The app does not create an account or save a personal session history to a database or browser storage area.

Refresh and reset are different

Reset clears the current in-page counters and timer while leaving the page open. Refreshing or closing the page removes the in-memory session as the page is unloaded. Neither action can delete a CSV file that you already downloaded.

CSV files are separate downloads

When you select Export summary, your browser creates a downloadable CSV file. The file is under your control after download and may remain in the browser's Downloads folder even after the application session has ended. Manage it with your device's normal file controls.

The offline cache stores app files

The service worker can cache static website assets to help the interface load again when offline. This cache is separate from the temporary counts and does not include camera frames or the user's active session data. You can clear it through browser site-data settings.

Key points

  • Session counts exist only in the active page memory.
  • Reset clears the current session values.
  • Downloaded CSV files are managed separately by your device.
  • The service-worker cache stores app resources, not camera frames or counts.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

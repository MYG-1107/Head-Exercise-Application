Camera mode

How Camera Mode Works

Camera mode uses a browser camera stream and a face-landmark model to estimate relative head direction. It is an assistive counter workflow, not a precise motion measurement system.

8 November 2026·Application help guide

Permission begins with your action

The browser asks for camera permission only after you press Start camera. The application then displays a live preview and loads the tracking library and model assets needed for camera mode. If permission is denied or camera access is unavailable, the application should show a status message and you can switch to manual mode.

Landmarks are interpreted as estimates

The tracking model identifies facial landmarks. The application compares selected positions with a neutral reference to estimate relative direction. It smooths candidate directions so that a single noisy frame does not automatically become a repetition. This still depends on a visible face and stable tracking.

Why results can vary

Lighting, glasses or other occlusion, camera angle, distance, movement speed, browser performance and model loading can all affect tracking. The application may miss a movement or show no face detected. Treat the direction as an estimate rather than an exact angle or clinical range-of-motion value.

Use manual mode when needed

You do not need to keep trying a camera that is unreliable or uncomfortable. Manual mode avoids camera access and records your selected direction after you complete a cycle. The application does not verify manual entries.

Key points

  • Camera access is requested after a user action.
  • The model provides estimates, not clinical measurements.
  • The camera can be stopped by pausing or ending the session.
  • Manual mode remains available as a non-camera alternative.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

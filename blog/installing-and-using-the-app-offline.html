Installing the Application and Using It Offline

The application can be installed from supported browsers and can cache its static app shell. Offline support is limited: manual mode is the intended fallback when the camera model cannot be loaded.

8 November 2026·Application help guide

Install from the browser

When the browser supports installation, use its Add to Home Screen or Install option. The exact label and availability depend on the browser and operating system. The manifest supplies the application name, icons and start URL used by supported install experiences.

Load once while online

The service worker installs after the site is opened and caches selected same-origin files. Allow the first visit to complete while connected. If installation or cache setup is interrupted, reload while online so the browser can finish fetching the app shell.

What works offline

The cached page shell and its local scripts can make the interface available when the network is unavailable. Manual mode is designed to work without loading the external face-tracking model. Offline availability can vary with browser storage policies and whether required files were cached successfully.

Why camera mode may need internet

Camera mode currently loads tracking code and model assets from an external CDN when the user starts the camera. Those assets may not be cached for offline use. If the model cannot load, use manual mode until you have a reliable connection.

Key points

  • Installation support depends on the browser.
  • Open the site online once so the service worker can cache app files.
  • Manual mode is the offline-friendly option.
  • Camera tracking assets may require an internet connection.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

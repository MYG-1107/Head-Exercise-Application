Neutral Position Calibration Explained

Camera mode needs a reference position before it can estimate relative direction. Calibration establishes that neutral reference from the face landmarks visible to the camera.

8 November 2026·Application help guide

What neutral means

Neutral is the comfortable forward-facing reference used by the counter. It is not a posture score and it does not tell you what position is medically correct. The application uses it as a baseline for interpreting later changes in the tracked landmark positions.

Allow automatic calibration to complete

After the camera starts and a face is detected, the application begins collecting a short set of stable samples. Keep your face visible and hold a comfortable forward-facing position while the progress indicator advances. If the face disappears, calibration may restart or wait for a stable view.

When to recalibrate

Recalibrate if the camera moved, the device position changed, the detected baseline seems unreliable or tracking has been interrupted. Use the on-screen recalibration control while a camera session is running. The new baseline replaces the previous reference for the current session.

Improve the camera view

Use even lighting, place the camera steadily and keep the face within the preview. Avoid forcing a rigid posture or holding an uncomfortable position. If a stable reference cannot be established, stop camera mode and use manual mode instead.

Key points

  • Calibration creates a tracking baseline, not a clinical assessment.
  • Keep the face visible until the progress indicator completes.
  • Recalibrate after changing camera position.
  • Use manual mode if a stable baseline cannot be obtained.
Use and safety note

This guide explains application features, not health treatment or exercise technique. The application is a counting utility, not a medical device or clinical assessment tool. Use only comfortable movement and seek qualified professional advice for health questions.

# Changelog

## v2.4.0 — QA, useful features and discoverability

- Added a user-triggered CSV session export with no server upload.
- Added an installable PWA manifest and an app-shell service worker for offline interface/manual mode after first visit.
- Added crawlable, original guide, privacy and safety pages while keeping the main tracker concise.
- Improved title, description, canonical, Open Graph, Twitter and WebApplication JSON-LD metadata.
- Updated robots.txt and sitemap.xml to include indexable support pages and accurate last-modified dates.
- Added static DOM/link/SEO/privacy checks to the test suite.
- Documented the limitations of SEO and the need for real-device camera QA.


## v2.5.0 — Content, trust and SEO

- Corrected canonical, social and structured-data URLs to match the `Head-Exercise-Application` GitHub Pages path.
- Added an editorial hub with 31 individual articles across health technology, medical software, engineering, business, finance, AI, cloud, networking and cybersecurity.
- Added page-specific article metadata, BlogPosting structured data, dates, categories, topic tags and related-reading links.
- Added clear GrapeCrux business-enquiry links without presenting the exercise tracker as a clinical product or implying an unverified case study.
- Added responsive article and blog-index styles, search and category filters, and sitemap coverage.
- Expanded site quality checks for article count, metadata, canonical URLs, structured data and internal links.
